 # Personal Project Showcase App

## Project Description

The Personal Project Showcase App is a Single Page Application (SPA) built with React. It allows users to view, search, and add projects dynamically. Each project contains a title, name, description, category, and image.

The application demonstrates React concepts such as components, props, state management, event handling, and responsive design.

## Features

- View a list of projects
- Add new projects dynamically
- Search for projects by title
- Display project images
- Responsive user interface
- Built using reusable React components

## Technologies Used

- React

- JavaScript (ES6)
- JSX
- CSS3
- HTML5
